# AgroLens — AI-assisted crop disease screening

AgroLens is a hackathon-ready web application that turns the supplied landing-page concept into a runnable full-stack prototype. A farmer uploads a leaf photo, the backend runs an image classifier and Grad-CAM visualization, and the report shows a plain-language summary, general care steps, and links to official crop-insurance resources.

## What's included

- Responsive green-and-white frontend with drag-and-drop image upload, preview, progress animation, heatmap view, and downloadable text report.
- FastAPI backend with `/api/health` and `/api/analyze` endpoints, upload validation, image size limits, and inference serialization for Grad-CAM.
- Real image-classification inference using a public 38-class PlantVillage-style model from Hugging Face. Model weights are **not bundled**; on the first analysis the application downloads them to the local Hugging Face cache (about 95 MB), so the first run needs internet access.
- Grad-CAM-based model-attention overlay, top predictions, confidence display, and crop-care suggestions selected from a small local advisory catalogue.
- PMFBY official resource link. The app never decides insurance eligibility; farmers must confirm notified crop/area, policy conditions and deadlines on official channels.
- A clear limitations message: the model is a screening aid, not an agronomist or lab diagnosis.

## Run on Windows

**Recommended:** Python 3.11 or 3.12 (64-bit), with internet access for installing dependencies and downloading the model once.

1. Extract this folder.
2. Double-click `start_windows.bat`, or open PowerShell in the folder and run:

   ```powershell
   py -3.12 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   Copy-Item .env.example .env
   python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
   ```

3. Open **http://127.0.0.1:8000** in your browser.
4. Upload a clear JPG/PNG/WEBP/BMP leaf photo (maximum 10 MB) and select **Analyze leaf**. First inference may take a few minutes depending on your internet and computer because the model is downloaded and initialized on-demand. Later requests reuse the cache.
5. API docs are at **http://127.0.0.1:8000/docs**.

If PowerShell blocks activation, use `start_windows.bat` or run `.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000` after installing dependencies.

## Run on macOS / Linux

```bash
chmod +x start.sh
./start.sh
```

Then open http://127.0.0.1:8000.

## Optional configuration

Copy `.env.example` to `.env`. By default:

```dotenv
AGROLENS_MODEL_ID=mesabo/agri-plant-disease-resnet50
```

You can point `AGROLENS_MODEL_ID` to another compatible Hugging Face `AutoModelForImageClassification` checkpoint, but its labels and preprocessing may differ. The default model and its class coverage are described in its [Hugging Face model card](https://huggingface.co/mesabo/agri-plant-disease-resnet50). Its card reports a PlantVillage benchmark; that should **not** be interpreted as the same accuracy on Indian field photos.

## API

### `GET /api/health`
Reports whether the API is running, which model is configured, and whether weights have been loaded.

### `POST /api/analyze`
Multipart form field: `file` (a leaf image file).

Example using curl:

```bash
curl -X POST http://127.0.0.1:8000/api/analyze -F "file=@leaf.jpg"
```

Returns predicted crop/disease, model confidence, top three predictions, a heatmap image data URL, general next steps, and PMFBY resource information. The image is processed in memory and is not intentionally saved by AgroLens.

## Government support information

The project links to the [official PMFBY portal](https://pmfby.gov.in/). PMFBY can cover certain eligible crop-yield losses due to notified risks, including pests and diseases, under applicable rules. Coverage depends on the relevant crop, location, insurance/policy and current notifications. An image prediction does not prove a loss, establish eligibility, or start a claim. Check the official portal promptly; it currently lists **14447** for queries, grievances and crop-loss reporting.

## Important limitations — please keep these in a hackathon demo

- This project is an **early-screening prototype**, not a production agricultural diagnostic service.
- The model is trained on curated PlantVillage-style images. It can misclassify photos from fields, unusual varieties, mixed symptoms, poor lighting or crops outside its supported classes.
- Softmax confidence is the model's relative class score, not a calibrated probability that a diagnosis is correct.
- Grad-CAM visualizes image regions that influenced the selected class. It does not segment or verify the true disease lesion.
- The advisory rules are general, rule-based text, not generated by a qualified agronomist. Do not use them as pesticide prescriptions. Always confirm the cause and any registered treatment with a local Krishi Vigyan Kendra (KVK), agriculture officer, or qualified crop specialist.
- PMFBY eligibility and reporting windows must be checked on official/current channels. AgroLens does not file claims or determine eligibility.

## Troubleshooting

**Model download or Hugging Face connection fails**
- Ensure your internet allows access to `huggingface.co` and retry the analysis. The model is loaded lazily, so the web page can open even before weights are cached.
- If a partially downloaded cache causes problems, close the server and consult the [Hugging Face cache documentation](https://huggingface.co/docs/huggingface_hub/guides/manage-cache) before clearing relevant cached files.

**Import or package error**
- Use Python 3.11/3.12 in a fresh virtual environment. Install with `pip install -r requirements.txt`.
- If the `torch` installation fails, follow the official [PyTorch installation selector](https://pytorch.org/get-started/locally/) for your operating system and CPU/GPU, then reinstall the remaining requirements.

**The heatmap is dim or blank**
- Grad-CAM support depends on the selected model exposing convolutional activations. The default checkpoint does. For alternate model IDs, verify its architecture.

**Port 8000 is already in use**

```bash
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8001
```

If you change the port, open that same port in your browser.
